# 熊猫图像数字化课堂 Demo

用于高中信息科技“图像编码 / 信息数字化”课堂，围绕一个核心学习链：

**采样 → 量化 → 编码**

程序默认显示 8×8 采样、4 个灰度等级。教师可只改变一个参数，让学生先预测，再观察结果。

## 文件

- `panda_digitization_demo.py`：主程序
- `panda_demo.png`：课堂大屏使用的熊猫图
- `panda_demo_small.png`：窄屏自动使用的小尺寸版本
- `panda_samples.json`：预计算的各采样网格平均 RGB 数据

> 熊猫图片来自本课 `assets/pandas.jpg` 的课堂素材，经裁切、缩放后生成本 Demo 的运行图片。

## 教室运行方式（Windows 10 / Miniconda / `pt` 环境）

把整个文件夹放到：

```text
D:\dt\panda-digitization
```

打开 **Anaconda Prompt**：

```bat
conda activate pt
cd /d D:\dt\panda-digitization
python panda_digitization_demo.py
```

程序运行时只使用 Python 标准库 `tkinter`、`json`、`pathlib`，**不需要安装 Pillow、numpy、matplotlib 或 py5**。

如需课前检查文件是否完整：

```bat
python panda_digitization_demo.py --self-test
```

看到：

```text
SELF-TEST PASS
```

即可。

## 建议课堂流程（约 8–10 分钟）

### 1. 先固定：8×8、4 灰度

先不点击参数，问：

> 这只数字熊猫为什么这么粗糙？如果只能改一个参数，你想改什么？

让学生提出“格子更多”“颜色更多”等猜想。

### 2. 只改变采样分辨率

保持 **4 灰度**不变：

```text
8×8 → 16×16
```

追问：

> 颜色选择没有增加，为什么轮廓仍然更细了？

收束：**空间位置更密，能表达更细的空间细节。**

### 3. 只改变量化等级

保持 **16×16**不变：

```text
4 灰度 → 6 灰度
```

追问：

> 格子数量完全没变，这一次改善的是什么？

收束：**可选数值更多，量化误差可以变小。**

### 4. 点击一个格子：走完“样本 → 码字”

点击左右任意图像中的同一个格子。底部会显示：

```text
样本平均 RGB
→ 灰度值
→ 量化后的颜色编号
→ 二进制码字
```

例如 4 灰度时，颜色编号只需要 2 bit；6 灰度时需要 3 bit。

建议追问：

> 6 种颜色为什么不是 2.58 bit，而必须用 3 bit？

强调本课讨论的是**固定长度编码**，每个像素使用整数个 bit。

## 支持的参数

### 采样分辨率

```text
8×8 / 16×16 / 32×32 / 64×64
```

### 灰度级数

```text
2 / 4 / 6 / 16 / 256
```

程序自动显示：

- 每像素位深度
- 可表示的二进制状态数
- 当前像素总 bit
- 折算后的 B

## 快捷键

```text
1 / 2 / 3 / 4   → 8×8 / 16×16 / 32×32 / 64×64
Q / W / E / R / T → 2 / 4 / 6 / 16 / 256 灰度
Ctrl+R           → 重置
```

## 教学边界

这个 Demo 是**概念模型**：每个采样格使用“格内像素的平均 RGB”作为该格的样本，再转换为灰度并量化。它用于帮助学生区分：

- **采样：在哪里、取多少个空间位置；**
- **量化：每个样本允许落到哪些有限数值；**
- **编码：怎样把量化后的编号写成 bit。**

它并不模拟真实相机传感器的曝光、Bayer 阵列、去马赛克、噪声等物理过程。这些内容不属于本节课的必要范围。

## 与课件的建议衔接

最适合放在课件“三轮熊猫实验”的位置使用：

```text
8×8，4色
→ 16×16，4色
→ 16×16，6色
```

演示结束后再回到课件，让学生概括：

```text
① 采样   ② 量化   ③ 编码
```

这样 Demo 是用来制造证据和认知变化，而不是替代课件讲解。
