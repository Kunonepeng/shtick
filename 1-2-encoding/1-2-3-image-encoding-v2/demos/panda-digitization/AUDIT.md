# Demo Audit / Review

## 已验证

- Python 语法编译通过。
- `--self-test` 通过。
- 运行时仅使用 Python 标准库。
- 8×8 / 16×16 / 32×32 / 64×64 的预计算样本矩阵尺寸均正确。
- 2 / 4 / 6 / 16 / 256 灰度对应位深度分别为 1 / 2 / 3 / 4 / 8 bit。
- 与课件一致的数据量校验通过：
  - 8×8 × 2 bit = 128 bit
  - 16×16 × 2 bit = 512 bit
  - 16×16 × 3 bit = 768 bit
- 在 1366×768 虚拟屏幕上实际启动并检查布局：无溢出。
- 在 1024×768 虚拟屏幕上实际启动并检查布局：启用紧凑布局后无文字截断。
- 窗口默认最大化；仍保留 Windows 标准最小化、还原和拖拽调整能力。
- 红色只用于当前选中单元格；紫色用于概念与当前参数，符合课件语义色规则。

## 审核后修复的缺口

1. **窄屏底部信息会被截断**  
   已增加 1024 宽屏幕的紧凑双栏布局。

2. **固定 448×448 图像在窄屏上占位过大**  
   已增加 `panda_demo_small.png`，屏幕宽度小于 1150 像素时自动切换 384×384 显示。

3. **“第 2 级”可能被误解为序数而非编码编号**  
   已改成“颜色编号 2”，与课件 0/1/2/3 的编号方式一致。

4. **需要避免把概念模型误讲成相机真实物理过程**  
   已在课堂说明中明确：Demo 使用格内平均值作为采样模型，不展开传感器内部实现。

## 仍然存在但可接受的边界

- 原始输入素材本身已经是数字图片，因此这是“用已有数字图像模拟再次采样与量化”的教学模型。
- 量化采用等间隔灰度等级，没有加入感知量化、抖动、调色板优化等高级算法；这是有意保持简单。
- Demo 聚焦灰度量化，不承担后续 24-bit RGB 三通道编码的全部教学任务。
