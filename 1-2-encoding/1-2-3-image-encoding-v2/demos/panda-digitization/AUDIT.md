# Panda Digitization Demo — Audit

## 目录与职责

放置位置：

```text
1-2-encoding/1-2-3-image-encoding-v2/demos/panda-digitization/
```

选择 `demos/` 而不是 `scripts/`：前者是**课堂直接运行的演示**，后者继续保留给 PPT / Quarto 构建与检查工具。

## 已核对

- Demo 使用本课已有熊猫素材的数据，不引入第二套无关图片。
- 采样参数只保留课堂真正需要的 **8×8 / 16×16**。
- 量化参数只保留课堂主问题链需要的 **4 色 / 6 色**。
- 默认状态为 **8×8、4 色、2 bit/像素**。
- 8×8 × 2 bit = **128 bit**。
- 16×16 × 2 bit = **512 bit**。
- 16×16 × 3 bit = **768 bit**。
- 4 色固定长度编码最少 **2 bit**；6 色最少 **3 bit**。
- 16×16 第 6 行第 5–12 列的四色量化结果与课件练习保持一致：
  `3 3 1 0 0 1 3 0` → `11 11 01 00 00 01 11 00`。
- 运行时只使用 Python 标准库：`tkinter`、`json`、`math`、`pathlib`。
- 不需要安装 Pillow / numpy / matplotlib / py5。
- 窗口默认最大化，并保留系统最小化、还原、拖拽能力。
- 屏幕宽度小于 1150 px 时自动改用紧凑布局。
- 紫色用于概念/当前参数；红色只用于当前选中格，符合本课 Violet-Rail 语义色规则。

## 本轮修正的缺口

1. **Git 版本不能依赖聊天会话中的临时 PNG 文件**  
   已改为提交 `panda_samples.json`；演示直接绘制采样 RGB 与量化结果，因此仓库 clone 后即可运行。

2. **原 Demo 的参数范围偏大**  
   32×32、64×64、2/16/256 灰度虽可演示，但会增加课堂分支。已收缩到本节课核心的 8×8 / 16×16 与 4色 / 6色。

3. **“采样”和“量化”在界面上容易同时发生**  
   现在左侧明确显示“采样后的 RGB 样本”，右侧显示“量化后的数字图像”，让两个步骤在视觉上分离。

4. **需要验证课件中的局部编码练习没有因数据重建而漂移**  
   `--self-test` 会核对第 6 行第 5–12 列的颜色编号与码字。

## 仍然存在、但属于有意保留的教学边界

- 输入源本身是数字图片，所以这是对“再次采样/量化”的概念模拟，不是假装真实传感器正在工作。
- 调色板量化使用 RGB 欧氏距离，是可复算的课堂规则，不等同于相机或专业图像编码系统的完整色彩处理。
- 本 Demo 聚焦索引色/有限调色板的采样、量化、编码；24-bit RGB 三通道编码留给课件后半段或独立 RGB Demo。
