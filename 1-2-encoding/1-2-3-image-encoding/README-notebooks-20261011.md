# 冻结课件的Notebook配套材料

对应`1-2-3-image-encoding-panda-v4-20261011.pptx`，当前85页；SHA-256：`aa2661338514e717294236bdad42c0bbba8acfa370148a53f9c89ab156c1521b`。这套材料不写入PPTX，不调用PPTX生成器。课程总入口仍是`course-design.qmd`的C0/C6。

## 打开与分发

- `demo-lab-teacher.ipynb`：教师备课与私下查阅，包含答案和追问，不投影全文滚动区。
- `demo-lab-student.ipynb`：教师课堂投影及学生加课时／课后实验，先预测再运行，无教师答案段落；输出与执行计数已清空。
- `demo-lab-teacher.qmd`、`demo-lab-student.qmd`：人工维护源。
- `demos/panda_lab.py`：两种视图共用的计算和显示函数。
- `assets/pandas.jpg`：用户原素材，保持原文件；实验不覆盖、不保存新图片到原路径。
- `fallback/teacher-evidence.html`：教师持有的离线实验结果；备课时可打开，不提前给学生。
- `validation/notebooks-20261011/`：两轮审查、修正核验和已执行副本，包含教师答案，不分发给学生。

课堂运行需要Python 3.11或更新版本及`requirements-notebook.txt`中的软件。构建另需Quarto、nbformat；执行验收另需nbclient、nbconvert。课堂无需Quarto。先在备课环境安装依赖，课堂不要临时安装。

便携包先解压，保留assets/和demos/的相对位置；它提供课堂运行材料。构建与完整验收在仓库课程目录进行，检查器还需冻结PPTX及既有Tk数据作为对照。

从课程目录启动：

```bash
python -m pip install -r requirements-notebook.txt
python -m jupyter lab .
```

Windows可在Anaconda Prompt激活已有教学环境后，`cd /d`进入复制的课程目录，再执行同一启动命令。打开Notebook后选择安装了上述依赖的Python内核；不要因内核名叫“Python 3”就假定环境相同。先运行准备单元；其余按教学进度运行。短操作的最小顺序是：准备→D3；准备→D4；准备→D10题面→D10证据。不需要把前面所有实验跑一遍。滚动到当前代码和两张证据同时可见，再讨论；已保存的输出不代表新内核已有变量。`Restart Kernel and Clear Outputs`可重置现场证据；不要保存运行后的答案到发给下一班的学生副本。

## 时长与备用路径

完整实验安排另加一课时（约40–45分钟）或分段课后完成，含独立预测、运行、记录、总结、E1。实际班级节奏尚未测试。

45分钟PPTX课堂可选择D3、D4、D10中的一项短操作替代对应证据讲解：预计各60–90秒，另留切换时间；不把12个实验全部加到原45分钟。D3在19页预测后、D4在25页预测后、D10在58页学生画图后运行；不要在开场运行整本。若超过30秒不能启动或取数，返回PPTX20、26–27、59–60页；离线HTML提供同样计算结果，失去的是改参数再跑的能力。

## 数据、单位与格式

原图886×1000，SHA-256：`f6679d0c7f119ec953e44be6912f03b2bd35bd032e27579241562b1bb46b5186`。固定裁切(280,100,288,288)，8×8每格36×36、16×16每格18×18。对解码RGB分块求算术平均，平方距离选最近调色板颜色，平局取较小编号；仅显示时取近似。不是线性光平均，也不模拟曝光、Bayer采样、噪声或去马赛克。调色板沿用课件及设计C4，不使用新增示意图片中的苹果或信号码字替换熊猫数据。

课件37、51–52页将÷1024的结果写成KB；Notebook用KiB并保留相同数值。499500B÷1024≈487.79KiB。总bit不整除8时，连续按字节打包需向上补位；完整格式的逐行对齐等还需另计。

E1的5色最少3bit指理想固定码模型；实际PNG索引位数只允许1、2、4、8。真实PNG示例选择合法位数，检查的是量化后的编号与RGB是否精确读回。不同版本编码器可能输出不同文件长度；不把具体PNG字节数作为考点。

原图由用户提供，公开再分发许可未确认。便携包用于本课备课／课堂复制，不能据此宣称可公开再分发；原素材与哈希保持可追溯。本任务未生成AI图片。

## 构建、写入与验证

在课程目录运行：

```bash
python scripts/build-panda-notebooks.py
python scripts/check-panda-notebooks.py --round final
python scripts/export-panda-notebook-kit.py --evidence final
```

构建只从两份QMD生成同名IPYNB，清除输出；若检测到Notebook正文人工改动或已保存执行输出，会拒绝覆盖，先保留修改并回收到QMD。共享模块是人工维护源。检查器把执行结果写入`validation/notebooks-20261011/`，不执行PPTX构建，不覆盖原图；离线HTML也是检查后的生成输出。检查前确认同名证据尚未包含人工修改。审查轮次目录和ZIP若已存在会拒绝覆盖；使用新轮次，或先保留原证据。本次正式便携包在exports/notebooks-20261011/；教师包与学生包分开，学生包不含教师答案、离线答案或审查副本。

校验结果及两轮分级问题见该目录的`audit.md`。本机内核执行、浏览器检查、Windows/JupyterLab、投影与班级节奏分别记录，不以一次Run All代替课堂阶段验收。
