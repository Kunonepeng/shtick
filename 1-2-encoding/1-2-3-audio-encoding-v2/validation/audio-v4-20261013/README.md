# 声音的数字化 v4：教学改进与构建说明

基线：同目录 `../../1-2-3-audio-encoding-v3.pptx`。v3 保留原字节，不覆盖。构建脚本：`build_v4.py`；产出：`../../1-2-3-audio-encoding-v4.pptx`。

## 本版对应的学习目标

围绕《普通高中信息科技课程标准（2017年版2025年修订）》必修1“数据与计算”内容要求1.1“通过案例分析，理解计算机中数据编码的基本方式”，让学生能解释：

- 声压变化如何转为可观察的时间波形；波形不是空间传播路径。
- 采样率决定每秒取样的数量，量化等级决定幅度的可选代表值，编码把量化等级表示成码字。
- 教学用8级/3bit模型与实际16bit PCM存储的区别。
- 未压缩PCM样本数据量如何由采样率、时长、声道数、每样本字节数决定。
- PCM解码与播放的基本闭环；为什么直接采样混叠图不能代替正常的“先滤波再采样”流程。
- 编码不一定意味着压缩，WAV文件字节数可能包含容器开销。

修改或补充相关原页的Speaker Notes。最终为60页：56页主线及原4页可选附录。

## 试听资源

`../../audio-v4-assets/` 文件夹含由脚本生成的四个WAV：
- `sampling-44100.wav` / `sampling-8000.wav`（相同合成音源，低采样率版本预先去掉高于可保存范围的成分）
- `quantization-3bit.wav` / `quantization-16bit.wav`（同16kHz采样率，比较实验性均匀量化）

音频放在课件旁边作为教师演示资源，**没有嵌入PPTX**；课堂上应使用本地播放器按Notes提示播放。音量较低，实际播放设备上仍需先检查。试听差异取决于设备、环境与听者，不能把“听不出区别”当作理解失败。

## 教学时间与设备检查

原v3已有45分钟预算，插入六页不意味着增加6次独立知识讲授。应把它们作为原概念的直观替代解释，压缩原有重复讲述；主线仍需在实际课堂试讲后调整。必要时先跳过量化试听，优先保留采样、量化、编码及PCM计数与退出评价。

授课机为Windows 10，需检查PowerPoint/WPS字体、Notes、波形线条、图示缩放、扬声器和本地WAV可访问性。推荐字体：Alibaba PuHuiTi 3.0 55 Regular和115 Black。Python脚本只用于重建，不是上课依赖。

## 可复现构建

在仓库根目录运行：

```bash
python -m pip install python-pptx
python 1-2-encoding/1-2-3-audio-encoding-v2/validation/audio-v4-20261013/build_v4.py
```

Python标准库负责生成WAV样本。构建过程不会修改v3。
