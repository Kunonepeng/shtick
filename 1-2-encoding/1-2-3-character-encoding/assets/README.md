# Encoding lab assets

Run this before the WinHex lab:

```bash
python 1-2-encoding/1-2-3-character-encoding/demos/create_lab_files.py
```

It generates:

- `assets/gb2312-lab.txt`
- `assets/utf8-lab.txt`

Both files contain:

```text
A中B国C文
```

The GB2312 file is intentionally generated by Python rather than committed as UTF-8 text, so the byte sequence is reproducible.
